# a530f-ota

Update index for an unofficial LineageOS 24.0 (Android 17) build of the Samsung
Galaxy A8 2018 (SM-A530F, `jackpotlte`).

The phone's Updates app reads `jackpotlte.json` from this repository and
downloads the build itself from the matching release. The build is attached to a
release rather than committed here, because it is about 1.08 GB and ordinary
files in a repository are capped at 100 MB.

`jackpotlte.json` holds an empty list whenever no build is published.
